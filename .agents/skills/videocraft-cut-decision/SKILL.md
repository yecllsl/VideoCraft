# 智能剪辑判读与删除清单

**核心原则**：判读不直接删语音；字幕文本可由 LLM 先校订、脚本确定性改写，但每处改动必须可审计并经过中间态一次确认。不确定项必须显式列出。工具契约以 `docs/agents/editing-mcp-capability-matrix.md` 为单一事实源，不在本文档复制参数表。

OpenCode 按 `description` 把本 skill 列入 `<available_skills>`，由 agent 按需加载；也可直接点名 `videocraft-cut-decision`。产出清单与校订表后交给 `videocraft-edit` 执行。

## 输入

- 用户侧：经 SMB 看视频、听语音。**agent 能读的是数据，不是声音**；不能真正听音时必须如实写明。口误裁决与校订结果在中间态片子由用户一次确认，不要求逐条判断。
- 每段话术：`transcribe_candidate` 的 `job.result.words`（词 / start / end / probability）与 `last_word_end`；`probe_media` 的媒体总时长。
- 空镜：`probe_media` 时长；入出点由用户看片确认，agent 未目检时不得虚构。列出每段空镜的 **SMB 完整路径 + 时长**，请用户按 `文件名: in–out` 回填；静态图片无法确定对应素材和入出点，必须索取「文件名 + 时间码」。需要联系表时用服务端受控 CLI 生成带时间码的抽帧。
- 帧预览：`extract_frames` 只是可选辅助，且受契约速查中的预览预算限制。拿不到帧时改用 SMB 看片或服务端 CLI，**不得据此推断画面，也不得把流程停在这里**。

## 四类删除原因

| 类别 | 判据 | 处理 |
|---|---|---|
| 重复 | 词序列在短时间内再次出现，或开头与后段语义高度相似 | 列候选并标「需核听」，不默认删 |
| 啰嗦 | 填充词（我觉得 / 然后 / 其实 / 非常的）密集，或词间长空隙 | 只列候选；删单个词会破坏语句连贯时不删 |
| 疑似口误 | 低置信词 + 语义不通 | 与 ASR 错词**从文本上不可区分**，一律标不确定项，不静默删除 |
| 末尾无意义 | `probe_media.duration - last_word_end` 的无语音尾部；首词 `start` 之前的空白 | 有客观时间依据，可默认建议删除 |

## ASR 同音 / 拼音化错词（LLM 先校订）

LLM 依据上下文与领域术语先做词级判断，产出**校订表**（原文 → 校订、置信 `high` / `medium`、依据），写进生成脚本的常量中；脚本只做确定性替换，不改语序、不补内容、不删对应语音、不动时间轴。`medium` / 低置信项列入「未改待判断」。

把识别错误当成口误删掉正确语音，仍是本流程最容易犯且不可逆的错误：**校订只作用于字幕文本，删除清单不受影响**。校订表随中间态一起交付，用户可逐条推翻；不做过的核听 / 目检不得宣称做过。

## 删除清单格式

轻量 Markdown 记录，放 `.scratch/` 或 `projects/<项目>/`，唯一命名，不含媒体副本：

- 状态：`待确认`（**只能由用户改为「已确认」**）
- 素材表：编号 / URI / 时长 / 类型
- 每段话术：保留片段（`start`、`audio_start`、`duration`、依据）、删除片段（区间、类别、依据、确定性：`客观` / `需核听`）、不确定项
- LLM 校订表（原文 → 校订、置信、依据）与未改待判断项
- 空镜：审定入出点；未目检时写「待用户指定」，给占位建议必须标明未目检。**「待用户指定」不是阻塞**，可继续完成话术判读与清单草稿，由用户一次确认时补齐
- 判读限制：如实写明是否核听、是否目检、依据来自哪些字段

同源取段时 `start` 与 `audio_start` 必须同值，否则音画不同步。

## 闸门

清单不是「已确认」时，不进入编排与提交，不产生成片。用户一次确认即授权后续自动完成；确认时可以勾掉某个删除项、改写空镜区间或补充核听结论。

话术 ASR 与空镜入出点互不依赖，可并行推进；只有连接 / 预检失败或审批闸门未置位才整体停止。工具失败先原样记录 `error_code` / `error_detail`，不得自行归因后停机。

字幕另有一道**中间态确认**：LLM 校订 + 脚本生成带校订字幕的片子（外挂或硬字幕）后交给用户看片确认；未确认不得当作定稿字幕。`videocraft-edit` 只回填实际结果，不得事后补写确认。

## 红线

- 未核听却宣称确认了口误；把 ASR 错词当口误删语音；LLM 校订不经中间态确认就定稿。
- 静默删除不确定项；复用样例区间、词表或偏移值。
- 要求客户端安装任何操作系统自带工具以外的工具。
